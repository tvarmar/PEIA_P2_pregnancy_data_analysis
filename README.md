# PEIA – Práctica 2: Análisis de datos de embarazo
Este repositorio contiene el trabajo correspondiente a la **Práctica 2** de la asignatura **Programación y Entornos de la IA (PEIA)**.

El proyecto consiste en un análisis exploratorio y descriptivo de un conjunto de datos de mujeres embarazadas, de carácter académico, que integra información demográfica, características del embarazo y parámetros de laboratorio. Se han
aplicado técnicas de limpieza de datos, visualización y análisis descriptivo para responder a las preguntas planteadas en el enunciado de la práctica.
## Contenido del repositorio
- `*.qmd`: archivo fuente del informe en Quarto
- `*.html`: informe renderizado
- `datos/embarazadas.xlsx`: conjunto de datos utilizado en el análisis
## Herramientas utilizadas
- R
- tidyverse
- Quarto
- ggplot2
- readxl
## Nota
El conjunto de datos utilizado tiene fines exclusivamente académicos y no contiene información personal ni sensible.
